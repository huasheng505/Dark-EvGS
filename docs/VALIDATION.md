# 验证记录

当前实例：Python 3.12.14，PyTorch 2.5.1+cpu；没有 NVIDIA GPU/nvcc。

执行：

```bash
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1 \
  /workspace/.venvs/dark-evgs/bin/python -m pytest -q tests
```

结果：**28 passed in 28.83s**。

覆盖范围：

- 数据：时间单位与共同时间轴、事件边界、不重复计数、极性、事件体素、时空邻域滤波、相机/图像映射、错误数据拒绝、无需时间戳的静态推理。
- 模型：非零几何/颜色/尺度梯度、优化后损失下降、遮挡合成、带主点偏移的投影矩阵、SH PLY 原格式往返和作者 Lion 检查点读取。
- 优化：增密/剪枝、保留 Adam 动量、点数预算、参数及随机状态恢复。
- 先验：CTMB/CTCM 前反向、辅助场景隔离、拒绝随机未训练权重、不同帧/事件时间单位、先验续训精确一致、防止覆盖已有结果。
- 端到端：独立辅助先验训练 → 8 张训练视图伪图 → 高斯训练 4 步 → 恢复至第 6 步 → 2 张留出图渲染 → PSNR/SSIM。与连续 6 步的高斯参数和统计缓冲逐项一致，输出图像非全黑。
- 评估：按图名匹配、已知误差的 PSNR、缺失图像/分辨率错误拒绝；未运行的 LPIPS 不记为通过或零值。
